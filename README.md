# 大型語言模型知識庫

從 [Wiki 索引](wiki/index.md) 開始閱讀。這個專案把論文、技術文件與研究筆記整理成可交叉查閱的繁體中文知識頁。

1. 把論文 PDF、文章文字或自己的原始筆記放進 [raw/](raw/)。也可以直接提供網址。
2. 在本專案和 Codex 說「請依照 AGENTS.md 收錄 raw/論文.pdf，更新相關頁面與索引。」
3. 提問時可以說「查 Wiki，整理 RAG 與微調各適合哪些情境，附上來源。」想保留回答時，再說「把這個比較存進 Wiki。」

[維護規範](AGENTS.md)包含來源引用與工作流程。[維護日誌](wiki/log.md)記錄每次收錄與檢查。可以用 Markdown 編輯器閱讀，也可以把專案資料夾開成 Obsidian Vault。
